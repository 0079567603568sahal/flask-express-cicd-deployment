# Automated CI/CD Pipeline on AWS (Flask + Express)

## 🚀 Overview
Built an automated CI/CD pipeline to deploy a Flask backend and Express frontend on AWS EC2 using Jenkins.

The pipeline triggers automatically on every GitHub push and redeploys services with zero downtime.

## 🛠 Tech Stack
AWS EC2 • Jenkins • GitHub Webhooks • Docker • PM2  
Flask • Express • Linux • CI/CD

## ⚙️ What This Project Demonstrates
- End-to-end CI/CD automation using Jenkins
- Automated deployments triggered by GitHub webhooks
- Multi-service backend & frontend deployment
- Process management and auto-restart using PM2
- Production-style Linux server setup on AWS

## 🔁 CI/CD Flow
GitHub Push → Jenkins Pipeline → Build & Install → Restart Services → Live Deployment
